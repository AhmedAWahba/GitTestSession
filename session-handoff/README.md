# Session Handoff

This folder preserves the important context from the UI bug-reporting session so work can continue after pulling the repository on another device.

## Start Here

1. Read `session-summary.md` for the chronological decisions and constraints.
2. Read `linear-bugs.md` for the created Linear issues and local report files.
3. Review the source reports under `../bug-reports/` before making follow-up edits.

## Scope

The session compared iOS app screenshots with design screenshots and drafted or published UI bug reports. The tested device context was iPhone 11, iOS 27.0, build 1.0 (3), unless a report says otherwise.

## Important Limitation

Screenshots attached directly in chat were visible for analysis but were not exposed as workspace files. They could not be copied into `evidence/` or uploaded to Linear from this session. Reports document that limitation instead of referencing unrelated images.

## Remote Changes

Linear issues were created for the reported bugs. GitHub issues were not created or modified by this workflow.
